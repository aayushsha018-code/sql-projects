# VENDMAT SQL ANALYSIS

## PROJECT OVERVIEW
This project analyzes a food ordering dataset (Vendmat) using SQL to extract business insights related to revenue, customer behavior, and sales trends.

## OBJECTIVE
To understand ordering patterns, identify high-performing items and locations, and support data-driven decision making.

## KEY ANALYSIS PERFORMED
- Total orders, revenue, and average order value (AOV)
- Orders and revenue by tech park
- Shift-wise and day-wise analysis
- Top-selling and highest revenue-generating items
- Revenue contribution (%) by tech park
- Repeat customer identification
- Ranking of items within each tech park

## TOOLS USED
- SQL (MySQL / PostgreSQL)

## KEY INSIGHTS
- Lunch generates the highest orders and revenue
- Friday is peak demand while Monday is lowest
- RMZ Azure Hebbal contributes the highest revenue (~35%)
- High-protein items generate higher revenue despite lower frequency
- Repeat customers significantly contribute to total revenue

## BUSINESS RECOMMENDATIONS
- Optimize inventory during lunch hours
- Introduce offers on low-demand days
- Promote high-revenue items
- Focus on high-performing tech parks
- Implement customer retention strategies
