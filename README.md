# SQL PROJECTS PORTFOLIO

This repository contains multiple SQL-based data analysis projects focused on extracting business insights from real-world datasets.

---

## PROJECTS

### 1. VENDMAT ANALYSIS
Analysis of food ordering data to understand revenue trends, customer behavior, and sales performance across tech parks.

### 2. DANNY DINNER CASE STUDY
SQL case study solving business problems related to customer spending patterns, visit frequency, and menu performance.

### 3. INSURANCE ANALYSIS
Analysis of insurance dataset to identify factors affecting medical charges, including demographics, smoking habits, and BMI.
