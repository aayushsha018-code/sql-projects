# DANNY DINER CASE STUDY

## OVERVIEW
This project analyzes Danny’s Diner dataset using SQL to answer business questions related to customer behavior, sales performance, and menu preferences.

## OBJECTIVE
To derive insights on customer spending patterns, visit frequency, and item popularity.

## KEY ANALYSIS PERFORMED
- Total spending by each customer  
- Number of visits per customer  
- Most popular items  
- First item purchased by each customer  
- Customer loyalty patterns  
- Ranking of items based on sales  

## TOOLS USED
- SQL (MySQL)

## KEY INSIGHTS
- Certain customers contribute significantly higher revenue  
- Popular menu items drive most of the sales  
- Repeat customers show consistent ordering patterns  
- Customer preferences vary based on visit frequency
